# Arquivos da IMP COMPANY

Esta pasta reúne os arquivos visuais utilizados pelo site.

## Organização

- `produtos/` — fotografias e mockups das camisetas.
- `identidade/` — logotipos e elementos visuais da marca.
- `banners/` — imagens de destaque e campanhas.

Use nomes de arquivos simples, sem espaços e preferencialmente em letras minúsculas. Ao adicionar imagens, mantenha os caminhos relativos a esta pasta no código do site.
